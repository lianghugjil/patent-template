# 审查避坑清单（实质审查高频驳回理由 → 写法对策）

> 定位：`audit_patent.py` 查"格式对不对"，`audit_exam_risk.py` 查"可形式化的实质缺陷"，
> 本文件管**两者都查不了、但审查员一定会问**的部分。
> 写稿阶段就把答案埋进说明书，比答复 OA 时再找材料便宜一百倍——答复阶段加内容受法第 33 条限制，加不进去。

---

## 二、逐条：审查员怎么问，我们怎么写

### 1. 法 2 条 2 款 —— 技术方案三要素

**审查员问法**：「该方案解决的是什么技术问题？采用了什么技术手段？取得了什么技术效果？」

**踩坑写法**：只描述结构长什么样，不写它为什么这样设计；或者效果只有"性能优良"没有因果链。

**对策（三件套必须都在正文里）**：
- 技术问题：背景技术末尾用「鉴于上述情况，有必要提供一种……，以解决……的问题」锁定；
  发明内容开头再用「本发明的目的在于提供一种……，使……」重复一次。
- 技术手段：每个结构特征后面跟一句**它起什么作用**（「……，从而避免……」「……，使……维持在……」）。
- 技术效果：有益效果段必须**结构特征 → 物理机制 → 量化结果**三跳齐全，不许跳步。

### 2. 法 22 条 3 款 —— 创造性（**主战场**）

**三步法**：① 确定最接近的现有技术 → ② 确定区别特征和实际解决的技术问题 → ③ 判断是否显而易见。

审查员只在 ② 和 ③ 上做文章：把区别特征说成"常规选择""惯用手段""有限次试验可得"。

**我们的弹药必须提前埋在说明书里**（答复时加不进去，只能从原文找）：

| 弹药 | 埋在哪 | 写法要求 |
|---|---|---|
| 区别特征带来的**意料不到的技术效果** | 有益效果段 | 有数字、有对比基准（对比例/现有方案参数） |
| **非线性的性能跃变** | 实施例 | 同一参数取不同值，指标出现突变（如 V/V\*=1.0 时增益从 28 dB 掉到 18 dB）——这是"不能通过有限次试验得到"的最强证据 |
| 克服了**技术偏见** | 背景技术 + 发明内容 | 先写"本领域通常认为……"，再写"本发明反其道而行，因为……" |
| 解决了**长期渴望但未解决**的问题 | 背景技术 | 「长期以来……始终未能……」 |
| **多重效果协同** | 有益效果 | 两个效果之间存在制约关系，本发明同时达成（如"释放末端空间"与"保持谐振增益"本来互斥） |

**反例（千万不要写）**：「本发明结构简单、成本低、易于推广」——这类不带数据的套话在创造性答复里一分不值，还会让审查员觉得方案没实质贡献。

### 3. 法 26 条 3 款 —— 公开不充分（**第二杀手**）

**审查员问法**：「该参数如何确定？」「所述效果如何测得？」「权利要求中的……在说明书中没有记载实现方式。」

**四类必查**：

1. **只给结论不给参数**：写了"优化设计"，却没给优化变量、范围、目标函数。
2. **参数不可获得**：写"取合适的壁厚"，没给取值范围和选取依据。
3. **功能性限定无实现方式**：权项写"用于抑制谐振的装置"，说明书必须有具体结构。
4. **效果无验证**：写了"信噪比提升"，没有测试条件（介质、温度、流量、仪器）。

**对策**：
- 每个设计参数给出**取值范围 + 至少一个取值点 + 选取理由（公式或物理解释）**。
- 每个性能数字给出**测试/仿真条件**（频率范围、边界条件、介质声速、采样点数）。
- 涉及公式时给出**符号表**（每个符号含义与单位），并至少给一组**算例代入**。

### 4. 法 26 条 4 款 —— 清楚 / 支持 / 必要技术特征

三种毛病分开治：

| 毛病 | 表现 | 修法 |
|---|---|---|
| 不清楚 | 权项有"约""左右""适当""厚""薄""若干"；用"或"连接可选方案导致范围不清 | 换成数值范围；把可选方案拆成从权 |
| 得不到支持 | 权项上位概括（"一种声学结构"），说明书只给了一个具体实施例 | 要么把权项收到实施例范围，要么在说明书补中间概括层级（概括句 + 至少两个不同下位实例） |
| 缺必要技术特征 | 独立权项少了实现发明目的必不可少的那一个特征 | 把该特征从从权提到独权（**注意**：这会缩小保护范围，先确认用户能接受） |

**独立权项自检口诀**：删掉任何一个特征，方案还能不能实现发明目的？不能删的才是必要技术特征。

### 5. 法 31 条 1 款 —— 单一性

**审查员问法**：「权 1 与权 3 是否属于一个总的发明构思？是否具有相同或相应的特定技术特征？」

**对策**：多个独立权项（产品 / 方法 / 系统）之间必须共享**同一个特定技术特征**，并在发明内容里明写一句
「上述各方案均基于……这一共同构思」。本技能默认把这句话放在发明内容总起段。

### 6. 法 33 条 —— 修改超范围（只影响答复阶段）

答复 OA 时只能做三类修改：① 删除权项；② 从说明书里**已有记载**的内容提到权项；③ 明显错误的更正。
**不能**新加没写过的参数、效果数据、实施例——加了就是超范围，直接把案子做死。

**所以本技能的第一原则是：写稿阶段把弹药备足，别指望答复时补。**

### 7. 细则 23 条 —— 摘要

- 文字部分**不超过 300 字**（含标点，不含附图标记说明）。
- 不得使用商业性宣传用语（"市场前景广阔""经济效益显著"）。
- 摘要只讲**技术方案要点**，不讲权利要求范围和法律效力。
- `audit_exam_risk.py` 的 J6/J7 会自动卡。

## 三点五、物理数值与边界条件自洽（审查员/对方代理人拿计算器三秒就能推翻的那类）

这一节不属于法条缺陷，但**杀伤力比形式缺陷大得多**：数字自相矛盾会被直接当成"方案没做过"，
创造性答辩时所有效果数据一起失信。三通稿 2026-10-23 一次通读命中六项，逐条记在这里。

| 类型 | 反例 | 反算 | 正确写法 |
|---|---|---|---|
| 频段与模态截止冲突 | 写"非轴对称截止 8.6 kHz"，又宣称"100 Hz～10 kHz 一维近似成立" | 评价上限 10 kHz > 8.6 kHz，前提已破 | 上限压到截止频率以下；或明写"高于该频率以实测为准，不外推一维近似" |
| 百分比漂移单侧/双侧混用 | ε=3% 时把基频 1097 Hz 写成"±66 Hz" | 1097×3%≈33 Hz；66 Hz 是峰间距 2194×3% | 单侧漂移 = f×ε；峰间距×ε 只属于峰间距。判据里先定义"温漂量"指哪一个 |
| 孔口流量不写介质 | "φ5 mm 孔、10 kPa 压差下通气量 90 L/min" | 水：Q=Cd·A·√(2Δp/ρ)≈3.2 L/min，差 28 倍 | 写明空气/水、表压/绝压、温度、Cd；气液两套数分别给 |
| 孔-腔共振漏端修正 | φ5×2 mm 孔 + 5 L 阀腔 → "共振 190 Hz" | 拿板厚当颈长算得 335 Hz；190 Hz 需 Leff≈6.2 mm（两端端修正各约 0.85d） | 写"计入两端孔口端修正的有效颈长"，或直接标"实测" |
| 绝对化表述 | "奇次峰族整体让位于整数峰族""V>V\* 后完全无峰" | 有限容积端接的反射相位连续变化，峰位连续移动 | 写"向…方向偏移""本实施例实测已明显偏离"；"整体让位"只留给 V→∞ 理想极限 |
| 边界条件不闭合 | 同段既说盲管末端是"刚性端"，又说"放气螺塞必须保持开启" | 螺塞开着就不是刚性端 | 写成工序：充水排气开、充满后关，运行态近似刚性端 |
| 理想化前提未声明 | 直接写"\|R\|=1""V\*=cS/(2πf₀)" | 建立在满液、无气囊、集中参数、无损之上 | 补一句"上述为理想近似，实际等效阻抗以注水试验/阻抗测试校准" |
| 单调性自变量不清 | "V\* 随 c 增大而增大" | f₀ 若取支管基频（随 c 变），c 与 f₀ 不独立 | 写"在目标频率独立给定且其他条件不变时…" |

脚本可查其中两条：`Y`（φd/kPa/L·min 三件套按水反算）、`Z`（Hz + 板厚反算有效颈长）；
其余必须人工反算——**写完全篇，拿计算器把每个"因此/代入得"过一遍**。

## 四、提交前最后一遍人工过（10 分钟）

1. 把独立权项逐条读一遍，问自己：**每个特征删掉还能不能实现目的？** 能删的就不是必要技术特征。
2. 把有益效果的每个数字回查：**说明书里有没有交代这个数字是怎么来的**（仿真条件/测试条件/公式）。
3. 把背景技术的缺陷与发明内容的目的**一一对应**：背景说了 3 个缺陷，目的就该有 3 个对应方案，不能有孤立的缺陷，也不能有凭空多出的目的。
4. 权项里的每个技术名词，在说明书里**第一次出现处有没有定义或结构说明**。
5. 参数跨章一致性：权项、发明内容、实施例三处出现的同一参数（如"预设倍数""预设容差"）**数值必须相同**。
6. 数字与单位之间、数值与范围符号之间**全文风格统一**（本项目用半角数字 + 空格 + 单位，如 `102 mm`）。
7. **附图首次引用顺序**：正文第一次出现的图号必须是 图1→图2→…（`audit_patent.py` S2 给出实际序列）；
   写"图2～图5"也算图2 先出场，会把顺序顶乱。
8. **反算三问**：这个频率/流量/百分比，用文中给的几何与工况能不能算出来？算出来差多少？
   差得多，是漏了端修正、错用了单侧/双侧，还是介质没写清？——三问过一遍，比通读三遍有效。
