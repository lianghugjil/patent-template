# 四类专利的骨架映射（结构 / 方法 / 算法 / 系统）

本技能的主骨架来自结构类装置专利。方法类、算法类、系统类**不是另起一套模板**，而是同一套骨架的
**参数替换**：章节顺序（权项 → 摘要 → 说明书 → 附图）、标号规则、页面版式、两套体检全部不变，
只换四样东西——

| 换什么 | 结构类 | 方法类 | 算法类 | 系统类 |
|---|---|---|---|---|
| ① 主题词 | 一种XX装置 | 一种XX方法 | 一种XX方法 | 一种XX系统 |
| ② 独权引导语 | 所述装置包括：A、B以及C | 包括以下步骤：步骤（1）… | 包括：获取…；对…；根据… | 所述系统包括：A模块、B模块 |
| ③ 标号体系 | 必须（父 1/2/3，子 101/102） | 涉及设备结构时必须有，纯工艺可无 | 通常无 | 模块编号可选，用模块名 |
| ④ 附图类型 | 外形/剖面/结构/原理 | 流程图 + 工艺曲线 | 流程图 + 框图 + 效果曲线 | 系统框图 |

**先判型，再动笔。** 判型只看独立权利要求 1 的主题词与引导语，不看标题：

```text
1.一种……方法，其特征在于，包括以下步骤：   → 方法类
1.一种……方法，其特征在于，包括：获取……     → 算法类（再看正文有无模型/训练/特征）
1.一种……系统，其特征在于，包括：……模块     → 系统类
1.一种……装置/设备/结构，其特征在于，所述…包括： → 结构类（默认）
```

---

## 一、结构 / 装置类（默认骨架）

- **独权**：`一种XX，其特征在于，所述装置包括：A、B以及C；所述A包括：A1、A2以及A3；`
- **标号**：强制。父件 1/2/3 严格连续，子件继承父号（101/102/103），正文每次引用都带号。
- **附图**：外形示意图 / 剖面图 / 结构图 / 工作原理图 / 数据曲线。结构图上**零文字**，只有数字标号。
- **说明书**：具体实施方式按标号部件逐段展开，每段"结构 + 连接关系 + 起什么作用"。
- **高频驳回**：法 26.3（只描述结构不说作用，公开不充分）、法 26.4（独权上位概括超过实施例）。
- **对应检查**：A~H 全项 + J9/J10（尺寸自洽）。

## 二、方法 / 工艺类

- **独权**（引导语固定，别写成装置）：

  ```text
  1.一种XX的制备方法，其特征在于，包括以下步骤：
  步骤（1）原料预处理：对原料A进行干燥与除杂，得到预处理原料；
  步骤（2）配比与混合：按预设配比将所述预处理原料与助剂B混合，得到混合料；
  步骤（3）成型：将所述混合料置于成型模具中，在设定温度与压力下成型，得到坯体；
  步骤（4）固化：对所述坯体分段升温固化；
  步骤（5）后处理：脱模并对成品进行尺寸与性能检测；
  所述成品的XX偏差不大于±1%。   ← 允许把产品特征写进方法权项的收尾
  ```

- **步骤编号固定用 `步骤（1）（2）（3）`**：全角括号、不带"第"、不写 `S1/S2`、不写 `1）2）3）`。
  理由：审查意见答复里"在步骤（2）中……"这种引用方式必须能一对一落地；`S1` 与 `步骤1` 混用会让
  引用链断裂。**同一篇内只允许一种编号风格。**
- **标号**：若方法里用到具体设备（模具、夹具、传感器），该部件仍要编号并进附图说明；
  纯化学反应/纯工艺路线可以全篇无标号——此时 `audit_patent.py` 的 D 项自动降级为提示，不报错。
- **附图**：**图1 必须是流程图**（否则 `audit_patent.py` 报 K3）。
  图注句式：`图1为XX方法的工艺流程图；` `图2为XX方法中固化温度随时间的变化曲线图。`
- **说明书**：具体实施方式逐步骤展开，每步写三件事——**做什么 / 参数取值与范围 / 为什么这么取**。
  参数不能写"适宜温度"，必须给区间 + 实施例取值点（否则 J4 与法 26.3 一起来）。
- **高频驳回**：法 26.3（步骤参数缺失、只说"适当"）、法 22.3（常规工艺简单拼接，缺意料不到的效果）、
  法 26.4（把非必要步骤写进独权，范围过窄）。
- **对应检查**：K1/K2/K3/K5 + J4/J8/J14。

## 三、算法 / 软件类

- **独权三件套**（强烈建议，缺载体权项会在侵权诉讼时吃亏；缺了 `audit_patent.py` 报 K4）：

  ```text
  1.一种XX方法，其特征在于，包括：
  获取待处理的XX数据；
  将所述XX数据输入XX模型，得到……；
  根据……确定……；
  ...
  8.一种电子设备，包括存储器、处理器及存储在所述存储器上的计算机程序，
    其特征在于，所述处理器执行所述计算机程序时实现权利要求1~7任一项所述的方法。
  9.一种计算机可读存储介质，其上存储有计算机程序，其特征在于，
    所述计算机程序被处理器执行时实现权利要求1~7任一项所述的方法。
  ```

- **客体红线（法 25 条）**：算法本身是"智力活动的规则和方法"，不授权。必须写成**技术方案**：
  - 处理的是**具体技术数据**（振动信号、图像像素、传感器时序），不是抽象数字；
  - 输出**用于控制具体设备或改进具体工艺**（调阀、报警、切换采样率、修正模型参数）；
  - 效果落到**技术指标**（信噪比、误报率、时延、功耗），不是"计算更快"。
  三句话要在**技术领域 + 发明内容 + 有益效果**三处都出现，缺一处就容易被 25 条打回。
- **公开充分（26.3）**：只给公式不给实现 = 公开不充分。必须写清——输入张量形状、超参取值范围与
  取值点、训练集来源与规模、损失函数、收敛判据、推理耗时。伪代码不进正文，写成"如式(1)所示"。
- **公式全部 OMML**（`$…$` 经转换器），不能是图片（否则 H 项报错，代理所也改不了）。
- **附图**：图1 流程图（判断框用菱形）、图2 系统/模块框图、图3 起效果曲线（黑白坐标）。
- **高频驳回**：法 25 条（客体）、法 26.3（公开不充分）、法 2.2（缺技术问题→手段→效果闭环）。
- **对应检查**：K1/K3/K4 + H（OMML）+ J8（效果必须有数据）。

## 四、系统 / 控制类

- **独权**：`一种XX系统，其特征在于，包括：数据采集模块、特征提取模块以及决策模块；`
  每个模块后面必须跟一句**功能限定**：`所述特征提取模块用于对……进行……`。
- **避免纯功能模块**：模块名后面没有"怎么实现"的，会被 26.4 认定得不到支持。
  说明书里每个模块都要有具体的算法/电路/器件落地。
- **附图**：图1 系统框图（矩形 = 模块，箭头 = 数据流）；有硬件结构时补一张结构示意图。
- **对应检查**：J12（模块名必须在说明书逐一找到）+ J13（有益效果）。

### 5.1 摘要附图默认取哪一幅

| 类型 | 摘要附图取 |
|---|---|
| 结构 / 装置 | 图1 整体剖视或结构示意图（一眼看全构成的那幅） |
| 方法 / 工艺 | 图1 工艺流程图 |
| 算法 / 软件 | 图1 流程图；若系统框图的信息流向更完整，取框图 |
| 系统 / 控制 | 系统框图 |

四条约束（详见 SKILL.md §1.1 与 `docx_format.md`）：复用同一幅、单独一页、不带图注、
缩到 4 cm × 6 cm 仍可辨（图幅按版心 60%~70%，不铺满）。


## 六、附图的文字例外（重要，别被 §4.2 误导）

SKILL.md §4.2 的"图上不得出现任何文字"**只约束结构类零件图**。以下三类图**必须有文字**，
否则图本身不成立：

| 图类型 | 允许且有必要的文字 | 限制 |
|---|---|---|
| 流程图 | 矩形 = 步骤（写步骤简称，≤12 字）；菱形 = 判断（写条件）；箭头 = 流向 | 不使用彩色、不使用 3D 立体框图、不用阴影 |
| 框图 | 矩形 = 模块，写模块名；箭头 = 数据/信号流向 | 同上 |
| 曲线图 | 坐标轴名称、刻度数字、图例（可用数字代称） | 坐标轴标签用中文短词；曲线不靠颜色区分，用实线/虚线/点划线 |

这三类图仍然服从**纯黑白线稿、无灰度填充、无装饰色、图号在图下、字号与正文相当**的底线。
`svg2dwg.py` 对流程图/框图的 `<text>` 走 `LABEL` 层 + `GB` 文字样式，中文可直接进 CAD。
