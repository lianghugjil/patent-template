# 专利模板 · 版式规范（页面 / 页眉 / 页脚 / 字体 / 段落）

> 全部数值从已提交专利申请文件（`说明书.docx`、`权利要求书.docx`、`说明书附图.docx`，
> 及 20 篇历史提交稿 r01~r20）用 python-docx + 原始 XML 逐项量出，20 篇页边距与页眉
> **完全一致**，可直接当作模板硬约束。

## 一、页面设置（Section）

| 项 | 值 | XML 字段（twips） |
|---|---|---|
| 纸张 | A4 210×297 mm | `w:pgSz w:w="11906" w:h="16838"` |
| 上边距 | 2.5 cm | `w:pgMar w:top="1418"` |
| 下边距 | **2.0 cm** | `w:pgMar w:bottom="1134"` |
| 左边距 | 2.5 cm | `w:pgMar w:left="1418"` |
| 右边距 | **2.0 cm** | `w:pgMar w:right="1134"` |
| 页眉距边界 | 1.5 cm | `w:header="851"` |
| 页脚距边界 | 1.75 cm | `w:footer="992"` |
| 装订线 | 0 | `w:gutter="0"` |
| 文档网格 | 按行，行网格 312 | `w:docGrid w:type="lines" w:linePitch="312"` |

> 注意：下/右边距是 **2.0 cm（1134）**（2026-10-21 定稿，原文为 1.5 cm/851）。
> 左右不对称：左 2.5 / 右 2.0，版心中心比纸张中心**偏右 0.25 cm**（142 twips）。

## 二、页眉（Header）

- 位置：居中，单行，**页眉下**带一条 0.75 pt 横线（`w:bottom w:val="single" w:sz="6" w:space="1"`），无下划线、无页码。
- **横线必须显式写入页眉段落**：Word 内置 `Header` 样式自带的下边框只在段落引用该样式时才生效，
  新建页眉段落通常不带，于是"页眉上没横线"。**做法**：在页眉段落 `w:pPr` 里写入 `w:pBdr`，
  只给 bottom 一条，其余五边 nil，位置在 `w:pStyle` 之后、`w:spacing` 之前：
  ```xml
  <w:pBdr>
    <w:top w:val="nil"/><w:left w:val="nil"/>
    <w:bottom w:val="single" w:sz="6" w:space="1" w:color="auto"/>
    <w:right w:val="nil"/><w:between w:val="nil"/><w:bar w:val="nil"/>
  </w:pBdr>
  ```
  `scripts/apply_patent_format.py` 的 `header_border()` 已实现，`--report` 在**缺**这条下边框时报 `!!`。
- **页脚不加横线**：页脚段落写六边全 nil 的 `w:pBdr`（`no_border()`），避免继承样式带的边框。
- 字体：**黑体 16 pt（三号）**，不加粗（黑体本身够重）。
- 文字：册名 + 字间留空。**每字之间一个全角空格 U+3000**（部分旧稿用 3 个半角空格，
  效果等同；新稿统一用 U+3000）。

| 册别 | 页眉文字 |
|---|---|
| 说明书 | `说　明　书` |
| 权利要求书 | `权　利　要　求　书` |
| 说明书摘要 | `说　明　书　摘　要` |
| 说明书附图 | `说　明　书　附　图` |
| 摘要附图 | `摘　要　附　图` |

> 册名**只出现在页眉里**，正文不写"说明书""权利要求书"这类标题行；
> 正文直接从"发明名称"（说明书）或权利要求 1（权利要求书）开始。

### 摘要附图页（**有附图就必须有**）

- 位置：说明书摘要之后、**权利要求书之前**；单独一节（分节符「下一页」），单独编页（页码从 1 起）。
- 页眉：`摘　要　附　图`，同样要有 0.75 pt 下横线。
- 内容：**只放一幅图**，必须是说明书附图中的同一幅（不得为摘要重画、不得拼接两张）。
- 图幅：按版心宽度的 60%~70%（≈10 cm）**居中**，不要铺满 16.5 cm 版心。理由：细则第 26 条要求
  缩到 **4 cm × 6 cm** 仍能分辨细节，摘要附图是缩小看的；铺满版心说明原图线条过密，应换一幅或简化。
- 页内除该图不写任何文字：不加"图1"图注、不加"摘要附图"字样、不加附图说明。
- 申请时还须在**请求书中指定**这一幅（细则第 26 条），交付话术里要提醒客户在 CPC 请求书里选图。

## 三、页脚（Footer）

- 内容：纯阿拉伯数字页码，`PAGE` 域（自动编号，不用手打）。
- 字体：宋体 12 pt，居中。
- 每册**从 1 开始重新编号**（`w:pgNumType w:start="1"`），页眉页脚随节切换。

## 四、字体

| 对象 | 中文字体 | 西文字体 | 字号 | 加粗 |
|---|---|---|---|---|
| 正文 | 宋体 | Times New Roman | 12 pt（小四） | 否 |
| 章节标题（技术领域、背景技术、发明内容、附图说明、具体实施方式） | 宋体 | Times New Roman | 12 pt | **是** |
| 发明名称（标题行） | 宋体 | Times New Roman | 12 pt | 否 |
| 页眉 | 黑体 | — | 16 pt | 否 |
| 页脚页码 | 宋体 | Times New Roman | 12 pt | 否 |
| 表格内容 | 宋体 | Times New Roman | 10.5 pt（五号） | 表头加粗 |
| 图注（图1、图2…） | 宋体 | Times New Roman | 12 pt | 否 |

字体设置必须**同时写 `w:ascii` / `w:hAnsi`（Times New Roman）与 `w:eastAsia`（宋体）**，
只写 `w:ascii` 会导致中文回落到默认字体。

## 五、段落

| 项 | 值 |
|---|---|
| 对齐 | 两端对齐（`w:jc w:val="both"`） |
| 行距 | **固定值 23 pt**（`w:spacing w:line="460" w:lineRule="exact"`；python-docx 用 `Pt(23)+EXACTLY`） |
| 首行缩进 | **2 字符**（`w:ind w:firstLineChars="200" w:firstLine="480"`） |
| 段前/段后 | 0 |
| 章节标题 | 无首行缩进，独占一行，加粗，其余同正文 |
| 发明名称 | 居中（纸张中心），`w:ind left="-142" right="142" firstLine="0"` 抵消左右边距不对称，不加粗 |
| 段中插图 | 居中，无首行缩进，段前段后 6 pt，**行距改为"最小值 23 pt"**（固定值会裁图） |
| 独立公式 | 居中，无缩进，段前段后 6 pt，**最小值 23 pt**（固定值会裁分式） |
| 表格内文字 | 单倍行距，无缩进，居中 |
| 孤行控制 | 关闭（`w:widowControl w:val="0"`，与语料一致） |

## 六、一键套用

```bash
python <skill>/scripts/apply_patent_format.py 目标.docx --volume 说明书
```

- 自动识别正文里的册名段（`说明书摘要`／`摘要附图`／`权利要求书`／`说明书`／`说明书附图`），
  在册名处**切节**、册名文字**移入页眉**、该节页码**重置为 1**。
- 幂等：重复运行不会叠加空行或重复页眉。
- `--report` 只体检不改文件。
